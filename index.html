Install in 3 Minutes. Zero Downtime.

Standard PostgreSQL extension protocol. Drop the binary and run one command.

1

Place the compiled binary (.so)

Copy the `.so` and control files to your PostgreSQL library directory:

sudo cp pg_solver.so $(pg_config --pkglibdir)/
sudo cp pg_solver.control pg_solver--0.1.0.sql $(pg_config --sharedir)/extension/
2

Enable Extension & Review Report

Activate the extension and view full before/after recommendations without changing anything:

CREATE EXTENSION pg_solver;
SELECT pg_solver_report();
3

Apply Optimizations Safely

One-click background creation with CONCURRENTLY. Revert anytime with `pg_solver_revert()`:

SELECT pg_solver_apply();
